# github-final-project

This project contains a Simple Interest Calculator written as a Bash script, hosted as an open source project on GitHub.

## Purpose
The script calculates simple interest based on user input: principal, rate of interest, and time period.

## How to use
1. Run the script: `bash simple-interest.sh`
2. Enter the principal amount.
3. Enter the rate of interest (%).
4. Enter the time period (years).

## Example
Principal: 1000, rate: 5%, time: 2 years
Simple interest = 100.00

## Formula
Simple Interest = (Principal x Rate x Time) / 100
